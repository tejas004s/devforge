# DevForge AI

A multi-agent software planning system that converts a high-level project idea into a detailed engineering plan.

DevForge AI simulates the workflow of a software development team using specialized AI agents. Each agent has a dedicated responsibility, such as gathering requirements, designing system architecture, planning implementation, reviewing quality concerns, and producing a final development report.

For example, a prompt such as:

> Build a hospital management system using React and FastAPI.

produces a structured project plan containing requirements, architecture decisions, API design, frontend structure, implementation strategy, and quality considerations.

---

## How It Works

The system follows a sequential workflow where each agent receives the output generated by previous agents.

User Input

↓

Project Manager Agent

↓

Architect Agent

↓

Implementation Engineer Agent

↓

QA Review Agent

↓

Final Report Generator

Each agent contributes a different perspective, allowing the final output to be more structured and complete than a single AI response.

---

## Agents

### Project Manager

Responsible for understanding the project idea and defining:

* Project objectives
* Functional requirements
* Non-functional requirements
* User stories
* Risks and success criteria

### Architect

Designs the high-level technical solution:

* System architecture
* Application components
* Database design decisions
* API architecture
* Security and scalability considerations

### Implementation Engineer

Creates the development plan for both backend and frontend.

Backend planning includes:

* FastAPI project structure
* Database schema
* API endpoints
* Authentication approach

Frontend planning includes:

* React application structure
* Components and pages
* State management strategy
* User workflows

### QA Reviewer

Evaluates the proposed solution by checking:

* Missing requirements
* Potential security issues
* Performance concerns
* Testing requirements
* Scalability challenges

### Report Generator

Combines the outputs of all agents into a final software development document.

## Running the Project Locally

### Backend

```
cd backend

pip install -r requirements.txt

uvicorn main:app --reload
```

The API will be available at:

```
http://localhost:8000
```

API documentation:

```
http://localhost:8000/docs
```

---

### Frontend

```
cd frontend

npm install

npm run dev
```

The frontend runs at:

```
http://localhost:5173
```
